# Personal Portfolio Website

Modern, responsive portfolio website built with React + Vite, featuring smooth on-scroll animations, a parallax hero effect, and a polished UI system built with Tailwind CSS.

## Author

- Name: Your Name

## Project Description

This project showcases my profile as a frontend developer, including:

- Hero section with role, intro, and CTA
- About section with short bio
- Skills section using visual icon cards
- Projects section with 3 featured projects and links
- Contact section with email, GitHub, and LinkedIn

It is optimized for mobile, tablet, and desktop breakpoints, and includes reduced-motion accessibility support.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- react-scroll-parallax
- React Icons

## Local Setup

### 1) Clone the repository

```bash
git clone https://github.com/your-username/personal-portfolio.git
cd personal-portfolio
```

### 2) Install dependencies

```bash
npm install
```

### 3) Start development server

```bash
npm run dev
```

### 4) Build for production

```bash
npm run build
```

### 5) Preview production build

```bash
npm run preview
```
